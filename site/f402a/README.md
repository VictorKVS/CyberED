1. Исходный материал остаётся отдельно от авторских улучшений CyberED/FATHER.

3. Лаборатория описывается по схеме **цель → стенд → конфигурация → проверка → доказательства → вывод**.

6. Исключить пароли, приватные ключи, токены, персональные данные и конфиденциальные документы из публичного репозитория.
7. Практики тестирования атак проводить только в собственных стендах или при явном разрешении.
8. Новые материалы добавлять последовательно; уже опубликованное не заменять без сверки версий.
