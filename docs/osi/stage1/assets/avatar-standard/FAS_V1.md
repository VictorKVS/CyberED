# FATHER Avatar Standard (FAS) v1.0 — проект стандарта

## Назначение
Повторно используемое лекало для любого 2D-аватара: один движок, разные character packs. Никакой повторной ручной подгонки размеров при смене персонажа.

## Геометрический контракт
- Канонический исходный холст: 1024 × 1024 px, RGBA, sRGB.
- Фиксированная точка взгляда: left_eye (0.38, 0.37), right_eye (0.62, 0.37), mouth (0.50, 0.62) — **начальные ориентиры**, подлежат калибровке на эталонном портрете, не являются универсальной анатомией.
- Координаты нормализованы 0..1; ни один кадр не может менять размер холста, масштаб головы или положение контрольных точек.
- Для портретов с плечами используйте отдельный layout preset; запрещено смешивать крупный план и поясной портрет в одной последовательности моргания или речи.
- Прозрачный фон предпочтителен; фон интерфейса задаётся отдельно.
- Исходник master.png сохраняется без изменений. Производные файлы имеют версию и хеш.

## Контракт анимации
- idle, listening, thinking, speaking, warning, happy, sad, nod.
- Blink: open → half → closed → half → open, 120–250 мс; случайная пауза 3–7 секунд. **Не активировать**, пока все пять кадров не прошли тест совмещения.
- Visemes: rest, MBP, FV, AI, E, O, U. Нужны согласованные изображения рта либо параметрическая маска. Произвольные фотографии не заменяют visemes.
- Переходы не должны сдвигать голову, очки, фон или плечи.
- Анимация отключается при prefers-reduced-motion.

## Речевой контракт
Input text → LLM/dialogue → TTS audio + word/phoneme timestamps → viseme timeline → renderer.
При отсутствии таймкодов — статичный портрет или нейтральная анимация без заявления о lip-sync.
Звуковое воспроизведение запускается только по явному действию пользователя.
Персональные данные не передавать в сторонние сервисы без необходимого уведомления и правового основания.

## Структура пакета
`characters/<id>/master.png`
`characters/<id>/avatar.json`
`characters/<id>/frames/idle.webp`
`characters/<id>/frames/blink_half.webp`
`characters/<id>/frames/blink_closed.webp`
`characters/<id>/visemes/*.webp`
`characters/<id>/voice.json`

## Quality gates
1. Размеры и alpha всех кадров идентичны.
2. Контрольные точки совпадают в пределах согласованного допуска (например, 3 px на 1024 px).
3. Нет скачков кадра при циклах idle/blink/speech; визуальная регрессия.
4. Рендер в мобильном и десктопном размерах, доступность и reduced-motion.
5. Звук синхронизирован с таймкодами, если объявлен lip-sync.
6. Интеграционный тест в реальном сайте обязателен до статуса READY.

## Миграция ALINA
Нынешние 39 WEBP — **reference contact sheet crops**, не сертифицированный FAS-пакет: разные ракурсы, масштабы, фон. Не включать автоматическое моргание/речь на них. Сначала создать один канонический master и совместимые слои, пройти QA. Текущий сценарный консультант не является голосовой LLM.
