# Alina Avatar Lite — исходники

Здесь хранятся эталонный портрет и согласованные анимационные слои.

Планируемый файл `alina_rig_reference.png` — концептуальный трафарет блондинки (глаза, рот, состояния), **не** готовый facial rig. Файл изображения загружается отдельно.

Перед подключением к `avatar-lab.html` необходимы базовый портрет высокого разрешения и прозрачные, совмещённые по координатам слои век и губ. Нельзя напрямую накладывать несогласованные миниатюры из концептуального листа.

Проверка: неподвижная голова, моргание без скачков, движение губ при Silero, возвращение в idle, трассировка событий.
