# CyberED Stage 1 — учебный сайт и агент ALINA IB

## Компоненты
- `student.html` — интерактивный учебный сайт из 8 модулей, с заданиями, контрольными вопросами, заметками и локальным прогрессом. Открывается напрямую в браузере без сервера.
- `alina_ib_agent.py` — детерминированный offline-планировщик аудита; **не LLM**, не проводит сканирования и не подтверждает соответствие.
- `example_system.json` — демонстрационная учебная ИСПДн.

## Запуск
```bash
python alina_ib_agent.py example_system.json -o audit_plan.json
```
Открыть `student.html` в браузере. Данные прогресса хранятся в localStorage браузера.

## Текущий охват
Сайт: теория, задания, ссылки на источники, базовые тесты. Агент: профиль ИСПДн/ГИС/КИИ/иная ИС, восемь типов узлов, перечни проверок, JSON-результат со статусом NOT_TESTED. Сайт и агент пока **не интегрированы по API**; обмен данными, проверка точных пунктов, БДУ, Top-100, реестры сертификатов, экспорт отчётов, авторизация и оценка преподавателем — следующий этап.

## Требования к промышленной версии
Контроль полномочий и области проверки, редакции нормативных документов, точные ссылки на пункты, доказательства и трассировка, журнал действий, разграничение ролей, проверка сертификатов, изолированное выполнение активных тестов, защита персональных данных, тесты и регрессия. Никаких выдуманных результатов аудита.
