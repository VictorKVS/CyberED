# Единый нормативно-технический граф FATHER / CyberED

Дата: 22.10.2026. **Проектная схема, не подтверждённая матрица обязательных мер.**

## Принцип
Один документ → версия → структурный пункт → атомарное требование → условия применимости → меры защиты → технические объекты → связи OSI L1–L7 (или вне OSI) → кандидаты СЗИ → сертификаты → тесты → доказательства.

## Реестры сущностей
| Реестр | Ключ | Обязательные поля |
|---|---|---|
| Documents | doc_id | ведомство, номер, дата, заголовок, редакция, официальный URL, статус проверки |
| Requirements | req_id | doc_id, точный пункт, текст/смысл, условие применимости, дата вступления, обязательность, исключения |
| SystemProfiles | system_id | тип АРМ/ГИС/ИСПДн/КИИ, класс/уровень/категория, границы, модель угроз |
| Controls | control_id | цель, реализация, методы проверки, связанные требования |
| Technologies | tech_id | OSI L1–L7 или вне OSI, протокол, оборудование, активы |
| Products | product_id | производитель, продукт, версия, комплектация, аппаратная платформа |
| Certificates | cert_id | регулятор, номер, область действия, срок, статус, URL, ограничения |
| Evidence | evidence_id | методика, результат, дата, ответственный, контрольный объект |

## Матрица применимости — пример, без автоматического назначения
| Профиль | Документы для проверки | OSI / домены | Кандидаты средств |
|---|---|---|---|
| Обычный АРМ | 149-ФЗ, локальные требования; при ПДн 152-ФЗ | вне OSI, L1–L7 | средства управления доступом, антивирус, журналирование |
| ИСПДн | 152-ФЗ, ПП 1119, ФСТЭК №21; ФСБ №378 при применении СКЗИ | вне OSI, L2–L7 | СЗИ НСД, МЭ, СОВ, СКЗИ по применимости |
| ГИС | 149-ФЗ, ФСТЭК №117, актуальные изменения; ФСБ №117 от 18.03.2025 при применимости СКЗИ | вне OSI, L1–L7 | МЭ, СОВ, СЗИ НСД, СКЗИ |
| Значимый объект КИИ | 187-ФЗ, ФСТЭК №235, №239, акты ФСБ по применимости | вне OSI, L1–L7 | СЗИ сетевой защиты, контроля доступа, обнаружения атак |

## Подбор сертифицированных решений
1. Установить применимость и необходимую меру, а не начинать с марки оборудования.
2. Найти сертифицированный продукт в [госреестре ФСТЭК](https://reestr.fstec.ru/), проверить действующий сертификат, требования безопасности, версию, состав и ограничения.
3. Для СКЗИ отдельно проверить сертификат ФСБ и условия эксплуатации, совместимость с системой и требования к классу.
4. Сопоставить сетевые характеристики: пропускная способность, HA, интерфейсы, протоколы, интеграция, поддержка, стоимость.
5. Испытать в составе целевой системы и зафиксировать доказательства; сертификат продукта не равен аттестации системы.

**Важно:** приказ ФСТЭК №117 и приказ ФСБ №117 — разные документы одного года. Не смешивать их.

## Правила качества
Нет точного пункта и проверенной редакции → связь только предварительная. Нет проверки сертификата → товар только кандидат, не «одобрен». Нет сквозного испытания → мера не считается внедрённой.
