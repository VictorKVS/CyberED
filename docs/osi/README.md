## Правила включения
1. `direct_osi`: документ непосредственно определяет OSI.
2. `network_security`: содержит сетевые технологии и меры защиты.
3. `regulatory_context`: регулирует системы/данные/сети без прямой ссылки на OSI.
4. Перед применением: проверить действующую редакцию, пункт, область действия, обязательность, изменения, источник.
5. ГОСТ не становится обязательным автоматически; необходимо отдельное правовое или договорное основание.

## Дальнейшая работа
Проверить ГОСТ по сериям 7498, 27033, 18045, 15408, сетевые ГОСТ Р и профильные приказы; привязать точные пункты к OSI L1–L7, технологиям, угрозам, СЗИ, тестам и доказательствам. Полные тексты скачивать только при наличии прав на распространение.
