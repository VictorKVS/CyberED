# POLYGON-001 — первая изолированная Ubuntu-лаборатория

Статус: DESIGN_ONLY / NOT_DEPLOYED.

## Цель
Развернуть FATHER-UBUNTU-01 в изолированном виртуальном сегменте, проверить доступность и конфигурацию, собрать доказательства. Предварительная спецификация: 2 vCPU, 4 GiB RAM, 40 GiB disk, Ubuntu Server 22.04 LTS. Это исходные параметры для проверки ресурсов, не утверждённая конфигурация.

## Обязательные предпроверки (READ_ONLY)
- OS edition/build, CPU, RAM, свободное место, состояние виртуализации, Hyper-V feature и модуль PowerShell.
- Существующие ВМ, виртуальные коммутаторы и IP-подсети (не менять).
- Проверка доступности лицензированного образа и его контрольной суммы.
- Проверка совместимости с Docker Desktop/WSL2 и имеющимися учебными стендами.

## Ограничения
Никакого внешнего bridge по умолчанию. Изоляция сети; исходящий доступ — только по отдельно согласованной политике. Никакого развёртывания при отсутствии подтверждённого GATE-1. Изменения выполняет TIMA с минимальными правами и журналированием.

## Критерии GATE-2
ВМ существует и работает; установленная ОС и версия подтверждены; ресурсы совпадают с утверждённой спецификацией; сеть соответствует модели; запрещённые маршруты отсутствуют; результаты тестов и конфигурации связаны с evidence_id. Ошибка любого критического теста → FAILED, а не READY.

## Этапы
P1: инвентаризация и выбор гипервизора → P2: архитектура и threat model → P3: GATE-1 → P4: TIMA dry-run → P5: разрешённое развёртывание → P6: GATE-2 → P7: проверенный кейс и PR знаний.
