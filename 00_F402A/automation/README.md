# CyberED × Алина — автоматическая база знаний ИБ

Этот каталог связывает сайт CyberED с локальным проектом `alina-knowledge-worker`.

## Что делает автоматика

1. Алина продолжает самостоятельно сканировать свои настроенные библиотеки.
2. CyberED обращается только к локальному API Алины на `127.0.0.1:8768`.
3. Синхронизатор получает состояние ИБ-библиотеки и поисковые фрагменты.
4. Выполняются поисковые профили: ФСТЭК, ФСБ, Роскомнадзор, ГОСТ, 152-ФЗ, 187-ФЗ, ПП РФ 1119 и ключевые номера приказов.
5. Для сайта создается `site/data/alina_ib_index.json`.
6. Оригиналы документов не копируются. Абсолютные пути диска в JSON не экспортируются.
7. Найденный фрагмент считается только кандидатом/источником, а не автоматически подтвержденным нормативным требованием.

## Запуск

Сначала должна работать Алина:

```powershell
cd "<путь-к-alina-knowledge-worker>"
.\.venv\Scripts\python.exe alina.py --serve
```

Затем во втором PowerShell:

```powershell
cd "G:\1\CyberED -IB\00_F402A"
.\automation\START_ALINA_IB_SYNC.ps1
```

Синхронизация выполняется раз в 60 секунд.
